# NIFA-RO V7 — Embedded Product Images

This version is designed to avoid missing-image problems on GitHub Pages.

## Why this version is different
All 8 appliance photos, all CSS, and all JavaScript are embedded directly inside `index.html`.
That means the product images will still appear even if GitHub Pages only serves the root HTML file.

## Publish
1. Extract the ZIP.
2. Upload `index.html`, `.nojekyll`, `404.html`, and the other files directly to the repository root.
3. GitHub → Settings → Pages.
4. Deploy from `main` and `/(root)`.

## Product prices
The store contains current public U.S. price references and links to the source pages.
Prices can change, so re-check them before commercial use.
